# Attendance Scenario Calculator

## Description
Attendance Scenario Calculator is a simple Python-based tool that helps students calculate their current attendance percentage and estimate their future attendance based on upcoming classes.

## Features
- Calculate current attendance percentage
- Estimate future attendance percentage
- Enter upcoming classes and expected attendance
- Compare attendance with a target percentage
- Simple and easy-to-use Python program

## How It Works
The calculator takes:
- Number of classes attended
- Total number of classes conducted
- Number of upcoming classes
- Number of upcoming classes you will attend
- Target attendance percentage

It then calculates and displays the expected attendance percentage.

## Formula
Attendance Percentage = (Classes Attended / Total Classes) × 100

## Technologies Used
- Python

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

5. Enter the required details when prompted.
