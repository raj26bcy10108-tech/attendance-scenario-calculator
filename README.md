# Attendance Scenario Calculator

## Project Description

Attendance Scenario Calculator is a Python-based project that helps students calculate their current attendance percentage and understand their attendance scenario.

## Features

- Calculates current attendance percentage.
- Checks attendance against the required percentage.
- Calculates approximately how many classes can be missed when attendance is above the requirement.
- Calculates how many consecutive classes need to be attended when attendance is below the requirement.
- Simple command-line interface.
- Uses only standard Python functionality.

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python attendance_calculator.py
```
